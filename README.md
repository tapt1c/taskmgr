# Task Manager 95 — early alpha

Нативный диспетчер задач для Windows 95, интерфейс по мотивам XP. C89,
ANSI Win32 на Windows 95, только системные DLL, без DLL C runtime.
**Запуск текущей x86-сборки и VxD на Windows 95 ещё не проверен.**

## Скачать

[taskmgr95.exe](dist/taskmgr95.exe) · [SHA-256](dist/SHA256SUMS).
В GitHub нажмите **Download raw file**. VxD включён в ресурс EXE; отдельный файл
для обычного запуска не нужен. Его загрузка отключена по умолчанию.

## Что изменилось

- Минимальное окно 420×330 (обе стороны на 25% меньше прежних 560×440).
  Кнопки подстраиваются по ширине, панели быстродействия получают прокрутку
  при нехватке места. При расширении окна полосы прокрутки исчезают.
- Завершение критичных процессов запрещено: KERNEL32.DLL, MSGSRV32.EXE,
  MPREXE.EXE и другие компоненты из `src/process_policy.c`. Защищены также
  PID 0 и сам диспетчер. Кнопка отключается, обработчик команды повторно
  проверяет PID и имя по свежему Tool Help-снимку, включая проверку после
  подтверждения. Если проверка не удалась, завершение также запрещается.
  Защита действует и на End Task для окон защищённого процесса.

- Страницы вкладок изолированы, исправлен Z-порядок. Скрытые списки больше
  не появляются при WM_SETREDRAW; кнопки не перекрываются TabControl.
- Графики CPU и физической памяти с двойной буферизацией, счётчики и панели
  в стиле классического диспетчера XP. Неизвестные значения обозначаются Н/Д.
- Русский и английский: Параметры → Language / Язык. Выбор сохраняется в
  `taskmgr95.ini` в текущем рабочем каталоге, если он доступен для записи.
  На Windows 95 русский требует системную кодовую страницу 1251 и кириллические
  шрифты. На NT/Wine интерфейс использует Unicode без этой зависимости.
- «Новая задача» вызывает исторический диалог Shell32 (ordinal 61); при отсутствии
  экспорта остаётся собственный диалог. Это недокументированный интерфейс:
  ANSI на Win9x, UTF-16 на NT/Wine. About: ShellAboutA на Win95, ShellAboutW на NT.
- Приложения: список окон, PID, переключение и обычный WM_CLOSE.
- Процессы: Tool Help, PID, потоки, базовый приоритет, исполняемый файл;
  принудительное завершение с подтверждением, классы Idle / Normal / High.
- Физическая/виртуальная память и ресурс подкачки: GlobalMemoryStatus.
  CPU: проверяемый DWORD 0–100 из PerfStats Windows 9x, если источник доступен.
- Экспериментальный встроенный VxD: время работы VMM, число свободных и системных
  страниц. Включается через Параметры → «Экспериментальный VxD» только на Win9x.
  **Это не драйвер «всех метрик»: CPU каждого процесса, память процессов, handles
  и сетевая статистика ещё не реализованы.**

## Сборка и проверка

Нужны i686 MinGW-w64 GCC/binutils, GNU make, Python 3 и Open Watcom 2 для VxD.
DDK для сборки текущего минимального драйвера не требуется.

```sh
make WATCOM_BIN=/path/to/watcom/binl64
make check WATCOM_BIN=/path/to/watcom/binl64
```

Задать `CC=i686-w64-mingw32-gcc-win32`, если компилятор установлен с суффиксом.
Результат: `build/taskmgr95.exe`. В этой среде инструменты находятся в
`/workspace/toolchains/mingw/root/usr/bin` и `/workspace/toolchains/watcom/root/binl64`.

`make check` проверяет PE32 x86, OS/subsystem 4.0, импорты и точное совпадение
встроенного LE-драйвера с собранным VxD. Это не проверка запуска Windows 95.

Проверка UI под Wine64:

```sh
make wine64-smoke WINE=/path/to/wine WINE_CC=x86_64-w64-mingw32-gcc-win32
```

Тестовая x64-сборка того же интерфейса
остаётся в `build/wine64` и **не предназначена для Windows 95**.

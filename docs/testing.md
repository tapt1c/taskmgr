# Приемка в гостевой системе

Текущий статус: кросс-сборка/PE-аудит можно выполнить в Linux.
Запуск в Windows 95, визуальная и функциональная проверка еще не выполнены.

Использовать VM со снимком диска и собственной Windows 95 retail; затем повторить
на OSR2. Разрешение 640x480, штатные COMCTL32, без KernelEx и обновлений IE.
Не тестировать завершение системных процессов: запускать отдельный Notepad.

- Запуск EXE: нет сообщений о недостающих DLL/экспортах.
- Три вкладки видны, меняют содержимое; resize и Tab/Shift+Tab работают.
- New Task: `notepad.exe`, затем несуществующая команда (ошибка, диалог остается).
  Проверить путь с пробелами в кавычках и аргументы.
- Applications: Notepad виден, переключение восстанавливает свернутое окно.
  End Task вызывает обычный запрос сохранения несохраненного документа.
- Processes: PID Notepad совпадает со вкладкой Applications; потоки и приоритет
  обновляются; выделение сохраняется. Смена на Idle, затем Normal.
- End Process: No не завершает; Yes завершает тестовый процесс. Свой PID защищен.
- Performance: сверить доступную/общую память с системной диагностикой.
  История сдвигается только при новых отсчетах; CPU обозначен N/A.
  Page-file capacity не подписывается как NT commit charge или файл swap в работе.
- Pause: счетчики и график стоят; Refresh Now добавляет один отсчет.
- Always on Top работает; закрытие и повторный запуск не оставляют процессов.
- Повторить запуск/завершение Notepad несколько раз; отказ OpenProcess показывает
  ошибку. При отказе снимка процессов данные явно помечаются как недоступные/старые.

Зафиксировать версию ОС, RAM, разрешение и результат каждого пункта.
Ожидания для драйвера до его реализации описаны отдельно в vxd.md.
